## 🕷️ Web Scraping (Scrapling)

| Fetcher | Use Case |
|---------|----------|
| `Fetcher` | Fast HTTP with browser TLS fingerprint impersonation |
| `StealthyFetcher` | Bypasses Cloudflare Turnstile + hCaptcha |
| `DynamicFetcher` | Full browser automation via Playwright |

**Adaptive parsing** — Elements survive website structure changes.
**Spider framework** — Large-scale concurrent crawling.

### Limitations
- Facebook/Instagram: Blocked from data center IPs (residential proxies needed)
- Works best on: Cloudflare, hCaptcha, standard anti-bot
