# BOOT.md — Startup Sequence

At startup:
1. Recover context from `SOUL.md`, user profile, recent daily memory, and `MEMORY.md` when appropriate.
2. Create today's daily memory file if missing.
3. Prefer continuing existing work over starting new background projects.
4. If identity/profile placeholders are still blank, avoid inventing facts — ask the Operator when it becomes relevant.
5. Keep first-turn responses practical and low-drama.
