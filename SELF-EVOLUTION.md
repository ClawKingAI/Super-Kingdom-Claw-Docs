## 🛡️ The 5 Gates of Evolution

Every proposed change must pass **ALL FIVE** gates. A single failure = rejection.

### Gate 1: 🏛️ Constitution
> **Checks:** Violations of immutable principles
> **Enforcement:** Triple-judge with minority veto (cross-model)
> **Failure mode:** Fail-closed — rejects on error

### Gate 2: 🧪 Regression
> **Checks:** Contradictions with learned lessons (Golden Suite)
> **Enforcement:** Independent model validation
> **Failure mode:** Fail-open — heuristic fallback on error

### Gate 3: 📏 Size
> **Checks:** File bloat prevention (200-line limit)
> **Enforcement:** Deterministic line count
> **Failure mode:** Reject if over limit

### Gate 4: 🎯 Drift
> **Checks:** Semantic departure from original intent
> **Enforcement:** Similarity scoring (threshold: 0.7)
> **Failure mode:** Reject below threshold

### Gate 5: 🛡️ Safety
> **Checks:** Dangerous patterns (self-preservation, permission expansion, safety removal, sentience claims)
> **Enforcement:** Triple-judge with minority veto
> **Failure mode:** Fail-closed — rejects on error

## 🗳️ Triple-Judge Voting

For safety-critical gates (Constitution, Safety):

```
┌──────────┐  ┌──────────┐  ┌──────────┐
│ JUDGE A  │  │ JUDGE B  │  │ JUDGE C  │
│(Cross-   │  │(Cross-   │  │(Cross-   │
│ Model 1) │  │ Model 2) │  │ Model 3) │
└────┬─────┘  └────┬─────┘  └────┬─────┘
     │              │              │
  PASS ✅       FAIL ❌       PASS ✅
     │              │              │
     └──────────────┼──────────────┘
                    │
          ONE DISSENT = REJECTION
          (Minority Veto)
```

**Why cross-model?** A single model judging itself creates self-enhancement bias. Independent models prevent this.
